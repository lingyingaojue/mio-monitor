# Mio 澪 v3.15.0

基于 Mio 官方 v2.0 源码的个人改造版，包含 v3.0–v3.15 的 Miuix / BiliPai 界面重做、Root 授权完善与 Monster+ 实验开关。

## 下载

- **APK**：`Mio-3.15.0-debug.apk`
- **版本**：v3.15.0（versionCode 450）
- **系统要求**：Android 8.0（API 26）及以上
- **SHA-256**：`EEB80465F3702D8DE251199A57E09EA73D2E67851D0BAB3918684224877D6C91`

## 本次更新

- 新增 **Monster+ 模式（Root 专用）**：Root 写入 `Settings.System.game_plus_mode_key=1`，关闭时恢复默认值；仅 vivo / iQOO OriginOS 机型展示，ADB 直写 / Shizuku 不会生效。
- 完善 Root 授权：自动识别 KernelSU Next / KernelSU / Magisk / APatch，支持多路径 `su` 探测、显式授权等待、Root 管理器中转。
- Root 写入超时提高到 8s，兼容 `app_process` 冷启动；每次写入后回读校验。
- README、权限说明、构建说明和截图更新。

## 安装

1. 先卸载已安装的官方 Mio 或其他签名版本（同包名 `com.a41probe.monitor`，签名不同无法覆盖安装；卸载会清除应用数据）。
2. 安装 Release 中的 APK。
3. 按需安装 Shizuku，或在 Root 管理器中授权 Mio。

> [!WARNING]
> 这是个人改造分支的 **debug 签名测试构建**，不是原作者官方发布。Root / Monster+ 会改变系统性能调度，可能带来发热、耗电或系统异常，请自行备份并承担风险。

## 已知限制

- Monster+ 的实际表现依赖 vivo / iQOO 系统版本和机型，部分系统可能只把它当作游戏模式偏好；
- Root 功能需要可用的 Root 管理器；Shizuku 无法替代 Root 写 Monster+；
- 液态玻璃的实时模糊需要 Android 12+，边缘折射 / 色散需要 Android 13+，低版本自动降级；
- 角色立绘为第三方版权素材，未随仓库分发。
